# 2.0.9 — 工具泛例与写入补齐

- 工具目录测试改为多个 agent 工具（apply_patch 只是示例），验证任意 agent 作用域工具都会进入完整目录。
- `tool-visibility` 增加 preset / agent / global 多来源回归用例。
- `/status`、`/presets` 按指定 workspace 读取技能视图，修复工作区独有技能在开关表中缺项。
- 保存按钮也走统一写队列，避免与预设应用/删除/导入并发覆盖。

> 2.1.0 说明：本版工具目录 / restrict 口径不变；2.1.0 的会话级合入**只作用于系统提示词段**，工具目录仍按纯预设装配计算（[ADR-0005](../adr/0005-universal-prompt-takeover.md) D6）。
