# 2.0.1 — 运行时上下文修复

- `tool:<name>:depth` 这类工具拥有的运行时上下文：工具不在当前候选目录或当前文本为空时不再显示，消除 `tool:subagent:depth` / `tool:subagent_fork:depth` 的残留项。
- 运行时上下文显隐改为编辑草稿：勾选只更新“预览含未保存草稿”，点「保存」一次写入；不再点一下立即刷新。
- `PromptContext` 的 `name/order/text/interpolate/required` 是宿主全部公开字段；插件不伪造 provider 元数据。
- 三阶段（引导期 / 常驻期 / 压缩受控期）使用同一套宿主 `assemble` 上下文；默认三阶段都返回，只有宿主显式 `suppressRuntimeContext()` 或 persona `includeRuntimeContext:false` 时才抑制可选上下文。
