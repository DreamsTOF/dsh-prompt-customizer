# 2.0.5 — 工具目录补扫与健壮性修复

- 预设工具目录新增 `catalogTools`：纯预设装配仍不混入会话提示词，但工具完整目录会扫描当前 agent 作用域，`apply_patch` 等客户端/agent 工具不再显示为消失。
- `/import`、`/restore`、`/config/set` 写入前按 Config schema 校验；非法 customization 返回 400，不再静默写坏数据。
- Skills 面板的静默轮询/焦点同步始终使用当前选择的工作区；`/presets?workspace=` 与 `/status?workspace=` 按工作区返回开关口径。
- 预设应用/删除/导入的多个配置写入由客户端串行队列执行，patch 失败不再继续写 `activePreset`。
- 上下文三态同步先预检全部阶段，再一次性写 draft，避免部分生效。
- 技能摘要缓存按 `scope + cwd + name` 隔离，并按宿主 rank 让内核 summary 覆盖同名文件扫描结果。
- `skill-health` 的 bundle 引用检查纳入 bundled / office / plugin 技能。
- 面板“刷新”同时重读 `/config`，避免旧编辑基线覆盖外部修改。
- 完整记录见本文件。
