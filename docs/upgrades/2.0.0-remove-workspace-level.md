# 2.0.0 — 移除工作区级提示词/工具层

## 破坏式变更
- 只保留**单预设编辑**：提示词 / 工具定制按 `overrides[presetId]` 保存和生效。
- 删除工作区级提示词/工具的 UI、查询参数、运行时装配与备份内容。
- `workspaceOverrides` 字段休眠：保留在 DB 中，不读、不写、不显示、不进备份；恢复备份也不删除既有休眠数据。
- 单预设编辑器提供导入 / 导出；设置页提供全部预设备份包与手动空 overrides 清理。
- 工作区概念继续用于 MCP、技能扫描和 cwd，不受影响。

## 代码归档
- 工作区级相关源码保留在原目录，但不再被入口、路由或构建装配接线；恢复时手动接线。
- 对应的旧测试移到 `test/archive/`，不进入测试门禁。

## 验证
- `npm run build`、`npm test`、host/client smoke 全绿。
- web 面板无“预设级 / 工作区级”切换与工作区选择器；单预设编辑、导入导出、清理按钮可见。
