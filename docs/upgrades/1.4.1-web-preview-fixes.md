# 1.4.1 — Web 预览/编辑运行时修复

## 修复
- 预设预览不再读取当前会话的 agent 作用域条目：`/preview` 返回纯预设 `baseSections` / `baseTools` / `baseContexts`，不再产生 `sessionOverlay`。
- 删除旧 `catalog_section` / `catalog_tool` DDL 与所有旧目录查询，避免旧 SQLite 文件触发 `no such table: catalog_section`。
- 运行时上下文只返回 `baseContexts`，上下文显隐写回配置时只保留 `{name, source}`，不再混入 `text` / `blocked`。
- 删除“左栏已并入当前会话”“会话变量尚未绑定”等过期提示。
- 保留工具阶段名单、提示词屏蔽/替换/注入和三态同步的保存路径。

- `npm run build`、`npm test`（141/141）、host/client smoke 全绿。
- 真实 web 预设矩阵：standard 24段/54工具/7上下文，ptc 25段/53工具/7上下文，minimal 9段/24工具/1上下文，cordis 24段/56工具/7上下文；三阶段一致。
- 浏览器实测：预设级引导期屏蔽段、工具可见性、上下文显隐保存后刷新仍保持；工作区级 ptc 的 `tools:ptc-only` 出现在 base 列表。
