# 1.0.0 —— 破坏式：自有存储迁移到 SQLite

> 破坏式更新：**不再兼容旧版 JSON / YAML 存储**。旧文件原样保留但**不读取、不迁移**。

## 变更

- 插件自有存储从多份 `config.yaml` / `catalog.yaml`（以及后续账本）统一为**单文件
  SQLite**：`~/.dsh/prompt-customizer/prompt-customizer.db`（WAL）。
  使用 Node 内建 `node:sqlite`，**无新增依赖**。
- 表结构见 `vendor/prompt-customizer/db.js`：
  - `doc(key, json)`：小型整份文档（`config`、工作区 overrides、各 MCP / 技能账本）。
  - `catalog_section` / `catalog_tool`：跨预设「全部提示词 / 全部工具」池，按行规范化存储。
  - `ledger(domain, scope, name, value)`：按条目读写的名单（预留）。
- 迁移范围：`config`、`catalog`、新增的**工作区级 override**、MCP `preset-masks` / `tool-disable` / `workspace-close`、技能 `preset-toggles` / `hidden-toggles` **全部进 DB**。宿主配置文件（`cordis.patch.yml` / `.mcp.json`）与技能根下的 `.bundles.json` 仍保持文件（不属于本插件账本）。
- **两级自定义**：预设级（`overrides[preset]`，只覆盖该预设作用域可见项）→ 工作区级（`workspaceOverrides[cwd]`，作用于该工作区所有会话、可覆盖会话里全部段/工具，且**覆盖预设级**）。面板顶部一个「预设级 / 工作区级」切换，SKILL / MCP / 提示词三 tab 共用。SKILL 工作区级为按 cwd 的技能/技能包开关（`skills/workspace-toggles`，优先级 工作区>预设>全局）；MCP 工作区级可整台 server 关闭（`mcp/workspace-close`）与逐工具启停（`mcp/workspace-tool-disable`）。
- 配置 API 不变（`createConfigStore` 的 `raw / readResolved / writeSection / setField`），
  但底层由文件换成 DB 的 `doc('config')`。
- 旧版 `~/.dsh/settings.yaml` 的历史段**不再一次性迁移**；`config.yaml` / `catalog.yaml`
  不再读写。

## 升级须知

- 首次启动会新建空的 `prompt-customizer.db`；用户需**重新配置**（旧定制不迁移）。
- 想回退：装回 0.x 版本即可（旧文件仍在原位、未被删除）。
