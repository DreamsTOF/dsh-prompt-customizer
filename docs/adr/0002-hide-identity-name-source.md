# ADR-0002：段/工具的隐藏身份采用“名字 + 来源”

- 状态：已采纳（2026-11-08）

## 背景
同名不同源很常见：某插件遮蔽了原生 `apply_patch` 并注册同名工具；提示词段也可能由不同 provider 注册同名项。
原先按“名字”去重/隐藏，会把不同来源的同名条目当成一个。

## 决策
- 段与工具的隐藏/显隐身份 = **名字 + 来源（source/provider）**。
- 工具页按来源分列同名工具：**遮蔽池显示原生**条目、**启用列表显示插件自带**条目。
- 旧配置中只有名字的隐藏名单**不迁移、忽略**（D9）。

## 后果
- 好处：同名不同源可分别控制与展示；遮盖关系清晰。
- 代价：需要来源信息；若某处来源缺失，需降级并标注“来源未知”。
- 兼容：旧名单忽略，可能使旧定制失效。

## 备选
- 仅按名字：无法区分同名不同源 → 否。
- 仅按 provider 内部 id：宿主未必稳定暴露 → 用“名字+来源”折中。
