# 2.0.13 — DSH 运行时契约对齐

- 工具目录按 `ctx.tools.definitions(scope)` 的注册定义识别来源，`locked-agent` 与 `masked-plugin` 行保留 `keySuffix`，同名遮蔽在 inventory/session 两条路径一致。
- `latestRootAgent` 改为复用按 `session.header.createdAt` 降序的 `listRootAgents`，不再假设 `agents.roots()[0]` 是最新会话。
- agent 来源匹配按 `source.kind='agent'` 跨会话匹配，预设配置不再绑定某个 session id。
- 工具可见性测试按宿主 `restrict` 契约拒绝 agent-local/未知名字；生成式 24 工具用例覆盖任意数量工具。

> 2.1.0 沿用：本页第 3 条「agent 来源按 `source.kind` 跨会话匹配」是 [ADR-0005](../adr/0005-universal-prompt-takeover.md) D4（清单身份稳定化）的前提。
