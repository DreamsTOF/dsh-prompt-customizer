# 2.2.0 — 面板 = 请求真值（生效视图同源）

版本 2.2.0，宿主契约不变（`engines.dsh: ^0.2.2-rc.1`）。本次改的是**面板数据源**与**只读池结构**，不改工具过滤的执行链路（`tools.restrict` / 阶段名单 / 装配后过滤 `assembly.tools` / `tools/pre-execute` 一律不动）。

## 缺陷（2.1.2 现状）

- 左栏主列表按纯预设 scope 的装配算（`vendor/prompt-customizer/index.js:1779-1782` 的取舍），结果是「面板能勾选」不等于「真实请求可见」。
- 2.0.15 的双行设计让同一工具同时出现 base 行（可勾选）与 masked 行（只读池），状态互相矛盾。
- PTC 折叠被显示成「工具都不见了」，既没说是折叠、也没说程序绑定内可用。
- 无活动会话时照常给结论，但此刻采不到 agent 作用域。

### pwsh 实例（dsh-ops 开「隐藏宿主 PowerShell」）

| 观测点 | 2.1.2（改前） | 2.2.0（改后） |
|---|---|---|
| 宿主行为 | agent 作用域 `tools.restrict` 裁掉 `pwsh` | 同 |
| 面板主列表 | 显示 `pwsh`，勾选框可用 | 不进主列表 |
| 只读池 | 与主列表并存一条 masked 解释行（双行设计），两处说法打架 | 只出现在不可反选组，`state = masked-plugin`、`layer = agent`，标「外部不可见」 |
| 取消勾选的后果 | 往阶段 `exclude` 写一条永不命中的条目，请求无变化 | 不可能勾选，不会写出无效条目 |
| 用户感知 | 「勾了没用」/ 以为自己关掉了 | 「这一项由外部决定，只读」 |

## 变更条目

- **`truth`**：`/preview` 新增 `truth: { linked, source, agentId?, ptcCollapsed }`，声明本次判定采到了哪一层。
- **`sectionPool`**：`/preview` 新增段的三层来源池（`layer` + `shadowedBy`），同名多来源在提示词域也可枚举。
- **工具行新字段**：`layer`（`global` / `preset` / `agent` / `executor`）、`ptcCollapsed`；`state` 新增 `masked-ptc`。既有 `hidden` / `scope` / `maskedByPlugin` / `maskedByOwnPlugin` / `maskedByShadow` / `shadowedBy` / `keySuffix` / `promptSections` 全部保留。
- **主列表口径固定**：可编辑 = `controllable` / `locked-agent` / `locked-executor`；`controllable && hidden` 带「本插件遮蔽」徽标、留原位、可反选。
- **只读池拆两组**：可反选组 `masked-own`；不可反选组 `masked-plugin`（外部不可见）/ `masked-shadow`（同名被覆盖）/ `masked-ptc`（PTC 折叠）。
- **两条横幅**：「未链接会话，外部可见性未知」（`truth.linked === false`）、「PTC 折叠生效：模型只收到 run_code，其余工具在程序绑定内可用」（`truth.ptcCollapsed === true`）。
- **自动刷新**：装配版本（`revision`）变化后重取真值，不点「刷新」也不留旧行。
- **文案术语拆分**：遮蔽（本插件可反选）/ 不可见（外部决定、只读）；「已遮蔽」池这个名字让位给只读池的两组。

## 行为变化（用户可见）

- 外部插件用它自己的 `restrict` / 账本裁掉的工具：从主列表消失，进只读池不可反选组，标「外部不可见」——不再假装可勾选。
- 本插件阶段隐藏的工具：仍在主列表原位（半透明 + 「本插件遮蔽」），可随时勾回。
- PTC / code-mode 预设：顶部出现折叠横幅，被折叠工具进不可反选组（程序绑定内可用）；提示词页不受影响。
- 无同预设活动会话：顶部出现「未链接会话，外部可见性未知」，主列表退回预设 scope 视图。
- 同名不同层：一行一个 `layer` 徽标，`shadowedBy` 指向顶掉它的那一行。

## 明确不纳入

- 不做跨插件归因（宿主无公开 API）：不可反选项不点名插件。
- 不改执行链路：`tools.restrict`、阶段 `exclude` / `add`、装配后过滤 `assembly.tools`、`tools/pre-execute`、遮蔽池的既有字段语义全部不变。
- 不改提示词域：PTC 折叠不作用于段；段的 `{name, source}` 去重与同名分列按 ADR-0005 不变。
- 不恢复累积池 / 跨预设枚举；`docs/guide.md` 里「池子是见过才知道的并集」段落仍是历史材料。

## 影响模块

- `vendor/prompt-customizer/index.js`：三层采样、`masked-ptc` / `layer` / `ptcCollapsed` 发射、`truth` / `sectionPool` 生成、1779-1782 注释改写。
- `src/client/prompt/`：`types.ts` / `tool-pool.ts` / `ToolsPane.tsx` / `locales.ts`（主列表口径、两组只读池、横幅、文案）。
- 测试：`test/effective-view.test.mjs`（新）、`test/preview-phase.test.mjs`（补）、`scripts/verify-panel-browser.mjs`（真浏览器）。
- 文档：`docs/adr/0006-effective-view-source.md`、本文件、`docs/guide.md`、`docs/testing/feature-matrix.md`、`docs/upgrades/README.md`。

## 回归点

| 回归点 | 观测 | 期望 |
|---|---|---|
| 主列表生效判定 | 外部 `restrict` 隐藏的 `pwsh` | 不在主列表；进不可反选组 `masked-plugin` |
| 本插件遮蔽留原位 | 阶段 `exclude` 隐藏的工具 | 仍在主列表、带徽标、可反选 |
| 双组只读池 | `masked-own` vs `masked-plugin` / `masked-shadow` / `masked-ptc` | 分别进对应组；不可反选组无勾选框 |
| 同名多来源枚举 | 同名工具 / 段在 global / preset / agent 三层 | 分列且 `layer` 正确；`sectionPool.shadowedBy` 指向被顶掉的来源 |
| PTC 折叠 | `truth.ptcCollapsed` 与提示词段 | 工具行进 `masked-ptc`；段清单 / 段预览不变 |
| 未链接会话降级 | 无同预设活动会话 | `truth.linked === false` + 横幅；不抛错 |
| revision 自动刷新 | 装配版本变化 | 面板自动重取，不留旧行 |
| 反例 | 主列表换回纯预设装配 / 给 `masked-plugin` 加勾选框 / `truth.linked` 恒 true | 对应用例必须失败 |
