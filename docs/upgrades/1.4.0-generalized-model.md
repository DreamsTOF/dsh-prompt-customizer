# 1.4.0 — 通用过滤模型（破坏式）

对齐 DSH `0.2.2-rc.1`。旧配置/快照**不迁移**。

> 本文记录 1.4.0 当时的行为，保留作历史材料。其中「工作区级」「预设级只叠通用会话项」已被后续版本修订：工作区级在 2.0.0 移除；会话级段的并入口径在 2.1.0 改为「同预设活动 agent 的真实装配」（[ADR-0005](../adr/0005-universal-prompt-takeover.md)）。

## 变更
- 三阶段由唯一 `PHASES` 描述表驱动，字段名/状态映射/工具目录不再三处手抄。
- 段、工具、运行时上下文身份统一为 `{name, source}`；`source` 为注册层
  `global` / `preset(id)` / `agent(session)` / `executor` / `workspace`。
- 名单（sections/contexts/tools exclude/add）存结构化 EntryRef；旧 name-only 名单忽略。
- `replace` 改为阶段化 `replacements: [{name, source?, phase, text}]`，只替换已存在段。
- 工作区级 = 预设候选超集 + 工作区 override：可隐藏但不可消失。
- 预设级只叠“通用会话项”（不属于任何已声明预设的 agent 条目），不叠具体会话的专属项。
- 运行时上下文按阶段独立显隐。
- `envBlocklist` 可配置、默认空；date/time/weekday 用 Intl 按宿主 locale/TZ。
- MCP：全局行读 `configEditor.entries()`；热重载用 `ctx.mcpManager.watch()` /
  `mcp-manager/status`；工作区 `.mcp.json` 按 cwd 匹配的 agent scope 挂载；
  删除第三方探活与自动改写。
- 中文提示词整功能、SectionView、sectionOps、旧 rescan 文案等死代码全部删除。

## 不再支持
- 旧 `replace` 字典、旧字符串名单、旧 catalog/目录池、旧中文提示词翻译、旧快照阶段键。
