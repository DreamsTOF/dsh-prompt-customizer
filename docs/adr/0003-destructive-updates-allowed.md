# ADR-0003：允许破坏式更新，不保留前向兼容

- 状态：已采纳（2026-11-08）

## 背景
本插件为单用户自用；历史遗留形状（如仅按名字的隐藏名单、目录池 catalog、旧快照结构）
对“按来源区分同名工具/段、预览=真实装配”等正确性目标形成阻碍。

## 决策
- **不为前向兼容写迁移/兼容补丁**。必要时可直接改变数据形状与语义；升级后可丢弃旧数据。
- 已按此执行：彻底移除 catalog；后续“名字+来源”身份、预览=真实装配均按最优形状实现，
  不兼容旧配置（旧隐藏名单忽略）。

> **2.1.0 注**：继续沿用破坏式、不迁移旧数据的决策；「预览 = 真实装配」的数据源口径由 [ADR-0005](0005-universal-prompt-takeover.md) 修订为「该预设 + 同预设活动 agent 的真实装配」。

## 后果
- 好处：实现更简单、语义更正确；无需维护多套兼容分支。
- 代价：升级后旧定制可能失效（可接受，单用户）。
