# DSH 0.2.0-rc.2 适配记录（0.9.2 纠正模式预设语义）

目标 tag `dsh-v0.2.0-rc.2`；实际 CLI `0.2.0-rc.2`，Node `24.18.0`。保留用户原有改动，不修改 DSH 源码。0.9.1 错误地把模式预设管理改成匹配在线对话，并在变量未绑定时清空整个视图；0.9.2 撤销这一方向。

| 接触点 | 当前行为 | 验证 |
|---|---|---|
| 1 源码补丁 | 从已求值 waterfall 保存段策略；forceSections 包装随卸载还原。complete 探测仍依赖隔离的私有 layers 读取。 | complete / 卸载测试 |
| 2 事件 | 继续调用 assemble waterfall 的 next；无新增会话事件。 | 阶段与草稿测试 |
| 3 Service | acquireScope 读取选中模式的当前修订，不匹配 Agent、不切换对话。请求成功或失败都释放租约。 | 多模式真实 Loader 与租约测试 |
| 4 文件系统 | 配置仍按 overrides[presetId] 保存；catalog 只为参考池，不能冒充该模式输入。 | 草稿不写盘测试 |
| 5 UI / 工具 | 删除会话选择器；model/cwd 未绑定时保留模板并附局部诊断。工具、正文、排序随模式变化。 | 零对话时 85/3 个独立工具、相反段顺序、模板快照 |
| 6 通道 | 复用 webServer 与 connection.requestRejection；删除错误新增的 sessions 路由。 | 认证 HTTP / 信任闸测试 |
| 7 进程 | 生产无新增进程；测试通过实际 dsh profile 冷启动，仅模型使用离线 fixture。 | 零对话多模式预览 → 用户消息/工具/回复 → 对话模式仍不变 |

## 仍需明确的边界

纯预设作用域不能获得只在 agent/created 注册、依赖具体会话状态的段和工具；不能用另一个对话替代，也不能把这种缺口当成不存在。三阶段仅模拟插件策略，不篡改已绑定对话。预览不是完整请求历史，不包含 assemble 后追加的 AGENTS/技能消息。PTC 模型目录可能不同于注册表。真实外部模型、多平台和用户当前 GUI 的视觉验证未覆盖。
